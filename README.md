# Reproducibility archive for exnexSurv

This archive contains the code, fixed inputs, result checkpoints, evidence exports, and figures needed to inspect and reproduce the analyses reported in the article.

> Fast EXNEX Log-Normal AFT for Right-Censored Basket Trials via Data-Augmented Gibbs Sampling

The archive is a reproducibility snapshot, not a second copy of the `exnexSurv` package; the development package remains at <https://github.com/victorney/exnexSurv>.

## Contents

- `figures/`: the three PDFs directly included by in the article.
- `01_generate_data.R`: deterministic data-generation code for all 13,000 archived trials.
- `02_fit_scenario.R`: fits the eight 12,000-trial simulation scenarios with four chains, 1,000 warm-up iterations, and 1,000 retained iterations.
- `03_analyze_article.R`: derives the article evidence exports from archived fit summaries; it does not fit models.
- `04_generate_article_figures.R`: regenerates only the three article figures.
- `05_tcga_application.R`: reproduces the observational TCGA illustration.
- `07_tcga_calibrated_simulation.R`: reproduces the 1,000-trial TCGA-calibrated simulation, with Stan restricted to its fixed subset.
- `08_noncentered_stan.R`: reproduces the centered/non-centered stress benchmark when the corresponding simulation inputs have been generated.
- `models/`: the three centered Stan comparators and the non-centered stress model.
- `fitted_models/scenarios/`: archived summaries for all nine scenarios, including the TCGA-calibrated archive-only scenario.
- `fitted_models/tcga_application/`: fixed TCGA application summaries and posterior-result snapshot.
- `fitted_models/article_exports/`: only the compact exports used to support article tables, figures, and stated computational diagnostics.
- `data/tcga/raw/`: the nine open TCGA clinical files used in the illustration.

`12_prior_sensitivity.csv` is retained because the submitted Discussion refers to that sensitivity analysis; its optional 500-fit driver is not needed for the main article and is not included.

`18_noncentered_stan.csv` and `22_gibbs_on_stan_stress.csv` are fixed stress-test evidence exports used by the Discussion. The former is regenerated by `08_noncentered_stan.R`; the latter is a derived summary retained from that benchmark. A blank divergence stratum in the latter means the centered diagnostic count was unavailable for that trial; it is not imputed.

The raw participant-level simulation files and large trial/basket audit CSVs are intentionally not duplicated here. The generator recreates those inputs; the archived checkpoints and compact exports preserve the results used by the article.

## Reproduction order

From this directory:

```text
Rscript 03_analyze_article.R
Rscript 04_generate_article_figures.R
```

Those two commands use the supplied checkpoints and do not run the long simulation fits. The generated CSVs and PDFs should match the supplied article evidence and figures up to software-dependent CSV formatting and plot rendering details.

To regenerate inputs for a selected subset:

```text
SIM_SCENARIOS=mixed,heterogeneous SIM_N_REPS=100 Rscript 01_generate_data.R
```

Then run `08_noncentered_stan.R` for the stress benchmark or `02_fit_scenario.R <scenario>` for a simulation fit. A full fit is computationally expensive and is not required to inspect this archive.

The TCGA script uses the immutable cBioPortal datahub commit `0cc9138746c08b304f8dac92c31983e0ef44af1d`; the raw files are already included, so it normally does not download them again.
